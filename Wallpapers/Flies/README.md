# 桌面苍蝇

在 DeskCanvas 壁纸库中选择“桌面苍蝇”并应用。也可以打开 index.html 预览，但真实桌面图标位置及桌面工具浮层需要 DeskCanvas 宿主。

- 背景透明，保留桌面原本的背景。首次应用在画面内生成 3 只苍蝇。默认每 5 分钟获得一次出生机会，优先孵化至少 30 秒的卵；只有苍蝇和卵均为空时才允许新的外来苍蝇进入。
- 活苍蝇默认最多 30 只，可在属性中设置 1 至 60 只；生成间隔可设置 1 至 30 分钟。数量上限以每个显示器为单位。
- 达到上限时卵保留在原地，下一次有空位的出生机会才孵化，不会一次集中孵化。
- 约 82% 的苍蝇偏好真实桌面图标区域，其余自由游走。图标位置每两秒刷新；隐藏图标或读取不到图标时自由游走。
- 苍蝇会飞行、爬行、停留、搓手、擦眼和产卵。飞入后不再越出画面。
- 按住 Alt，鼠标旁显示苍蝇拍；左键拍打附近区域。每只苍蝇两次命中后死亡，第一次受伤会短暂停顿并减速。
- 按住 Ctrl，鼠标旁显示扫把；左键打扫半径 42 像素的小区域。卵和尸体各自被扫到两次才消失。同时按住两个键时优先清扫。
- 工具仅在鼠标位于桌面且此壁纸没有暂停时生效，工具点击不会打开或选择桌面图标。普通鼠标操作不变。
- 卵最多 90 个，尸体最多 60 具；尸体超过上限后移除最早的尸体。动画默认 30 FPS，设备像素比最多 2。
- 暂停时生态计时一并暂停。切换壁纸或重启后重新开始，不累计离线出生。

壁纸在 Windows 图标层后方，苍蝇不能覆盖系统图标本身，但会在图标周围及其区域内活动。工具采用不抢焦点、点击穿透的原生浮层，可显示在图标上方；系统原有光标作为落点标记保留。预览模式没有真实图标，也不会改变系统桌面。
